# 📘 一企一册 · 实践学期学习手册一键生成

> 输入企业信息、专业方向、实践周期，一键生成结构完整的 Word 学习手册（.docx）

## 这是什么

**一企一册** 是一个通用型的实习/实践学习手册自动生成工具。  
只要提供企业名称、基本信息、岗位方向、实践周期，即可自动生成包含 **通用部分 + 专业部分** 的完整 Word 文档。

### 文档结构

```
封面 → 目录 → 通用部分 → 岗前培训 → 专业部分（4节）
├── 一、企业概况（基本情况/组织架构/主营业务/服务内容）
├── 二、安全规范与应急处理
├── 三、沟通协作基础
├── 四、职业守则
├── 岗前培训记录表
├── 一、岗位职责与任务
├── 二、岗位工作流程与标准
├── 三、实践任务与进度安排（教学安排 + N周周记）
└── 四、考核评价标准（多维度评价 + KPI考核）
```

### 特点

- **通用性** — 任何企业、任何岗位、任何专业、任何周期
- **自动化** — 一键生成完整 docx，无需手动排版
- **规范化** — 字体/行距/分页/目录均按高校教学文档标准
- **可定制** — 考核内容根据岗位方向自动匹配

## 快速开始

在 QwenPaw 中对话：

> "帮我生成一企一册，企业叫xxx科技，做电商开发的，8周"

Agent 会自动：
1. 询问或接收企业基本信息
2. 匹配岗位方向与考核要素
3. 生成完整的 docx 文档

## 技能包内容

```
yiqi-yice-skill.zip
├── SKILL.md                    # Agent 使用说明
└── word-template-reference.md  # 参考模板与代码模式
```

## 技术栈

- **Python** + **zipfile** — 直接操作 docx ZIP，无需 python-docx
- **XML 模板替换** — 从模板复制预置表格，替换 document.xml
- **手写目录** — 不使用 TOC 域代码，兼容各版本 Word
