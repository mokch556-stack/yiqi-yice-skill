# 📘 一企一册 · 实践学期学习手册一键生成

> 根据企业信息、专业方向、实践周期，一键生成完整的 Word 文档学习手册（.docx）

## 这是什么

**一企一册** 是面向高校实践学期/实习环节的文档自动生成工具。  
输入企业信息、专业方向、实践周期，即可生成结构完整、格式规范的 Word 学习手册。

### 文档结构

```
封面 → 目录 → 通用部分 → 岗前培训 → 专业部分
├── 企业概况（基本情况/组织架构/主营业务/服务内容）
├── 安全规范与应急处理
├── 沟通协作基础
├── 职业守则
├── 岗前培训记录表
├── 岗位职责与任务
├── 岗位工作流程与标准
├── 实践任务与进度安排（教学安排 + N周周记）
└── 考核评价标准（评价表 + 成绩核定 + KPI考核）
```

### 支持场景

| 岗位方向 | 示例企业 | 周期 |
|----------|----------|------|
| 电商平台开发/运营 | 互联网科技公司 | 8周 |
| 电商内容制作/短视频 | 文化传媒公司 | 8周 |

## 安装

将 `yiqi-yice-skill.zip` 解压到 QwenPaw 的 skill_pool 目录：

```bash
unzip yiqi-yice-skill.zip -d ~/.qwenpaw/skill_pool/yiqi-yice/
```

然后在 `skill.json` 中注册。

## 使用方法

在 QwenPaw 中对话：

> "帮我生成一企一册，企业是xxx，8周，电商内容制作方向"

Agent 会自动：
1. 收集企业信息
2. 匹配岗位考核要素
3. 生成完整 docx 文档
4. 输出到指定目录

## 技能包内容

```
yiqi-yice-skill.zip
├── SKILL.md                    # Agent 使用说明
└── word-template-reference.md  # 参考模板（含完整代码模式）
```

## 技术栈

- **Python** + **zipfile** — 直接操作 docx ZIP，不使用 python-docx
- **XML 模板替换** — 从模板复制 17 个预置表格，替换 document.xml
- **手写目录** — 不使用 TOC 域代码，手动生成带页码目录
